# Project Brief

## 프로젝트 개요
배달 전문 중식당 **「남다른 음식」**을 홍보하는 단일 페이지 랜딩 사이트입니다. 중식 메뉴 소개와 실제 고객 평가를 함께 보여주어, 방문·주문 전환을 유도하는 것이 목적입니다.

## 목적
- 「남다른 음식」의 브랜드와 대표 중식 메뉴를 한눈에 전달
- 고객 리뷰·평가를 통해 신뢰감과 주문 동기 부여
- 배달 주문으로 이어지는 CTA(행동 유도) 제공

## 핵심 목표
1. **메뉴 홍보**: 대표 중식 메뉴(이미지·설명·가격 등)를 매력적으로 노출
2. **사회적 증거**: 사용자 평가·리뷰로 맛과 서비스 품질 입증
3. **주문 전환**: 배달 앱 링크·전화·주문 CTA로 즉시 행동 유도
4. **반응형 UX**: 모바일(배달 주문 다수)과 데스크톱 모두에서 자연스러운 경험

## 범위

### 포함
- 단일 페이지 랜딩
  - Hero (브랜드 소개, 핵심 카피, 주문 CTA)
  - 메뉴 소개 (대표 중식 메뉴 카드/그리드)
  - 고객 리뷰 (평점, 후기 텍스트, 작성자)
  - 배달·주문 CTA
  - Footer (매장 정보, 연락처, 배달 앱 링크)
- 반응형 스타일링
- Next.js 정적 빌드 + **GitHub Pages** 배포

### 제외 (초기)
- 온라인 결제 / 장바구니
- 실시간 주문·재고 연동
- 리뷰 CMS / 관리자 패널 (정적 데이터 또는 하드코딩)
- 회원가입·로그인
- 다국어

## 비즈니스 가치
- SNS·광고·QR 등으로 공유 가능한 홍보용 랜딩
- 메뉴·리뷰 갱신만으로 지속 활용 가능한 마케팅 자산
- 배달 전문점 특성에 맞는 모바일 우선 전환 페이지

## 성공 기준
- [ ] 「남다른 음식」 브랜드와 중식 메뉴가 3초 안에 전달됨
- [ ] 대표 메뉴 3~6종이 시각적으로 매력 있게 노출됨
- [ ] 고객 리뷰 섹션이 신뢰감 있게 표시됨
- [ ] 배달 주문 CTA가 모바일에서 누르기 쉽고 동작함
- [ ] 모바일·데스크톱 레이아웃이 깨지지 않음
- [ ] GitHub Pages URL에서 CSS·이미지·링크가 정상 동작함
