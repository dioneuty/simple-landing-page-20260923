# Product Context

## 브랜드
- **상호**: 남다른 음식
- **업종**: 배달 전문 중식당
- **포지셔닝**: 일반적인 중식 배달과 차별화된 맛·품질을 강조하는 「남다른」 경험

## 해결하는 문제
- 배달 앱 목록 속에서 매장만으로는 차별점·대표 메뉴·고객 만족도를 충분히 전달하기 어려움
- 광고·SNS 유입 방문자에게 **한 페이지에서** 메뉴 매력과 신뢰(리뷰)를 동시에 보여줄 필요
- 주문 직전 고객의 **망설임(맛·양·배달)**을 리뷰와 메뉴 정보로 해소

## 타겟 사용자

### 1차 (주요)
- **배달 주문 고객**: 저녁·점심 시간대, 모바일로 메뉴 탐색 후 주문하는 사용자
- **신규 고객**: 광고·지인 추천·SNS 링크로 처음 방문하는 사용자

### 2차
- **재주문 고객**: 대표 메뉴·신메뉴 확인 후 빠르게 주문

## 사용자 경험 목표
1. **첫 3초**: 「남다른 음식」이 배달 전문 중식당임을 즉시 인지
2. **메뉴 탐색**: 대표 중식 메뉴를 사진·이름·한 줄 설명으로 빠르게 파악
3. **신뢰 형성**: 실제 고객 평가·별점으로 맛·양·배달 만족도 확인
4. **주문 전환**: 배달 앱·전화·주문 버튼으로 friction 없이 행동

## 주요 페이지 구성

| 섹션 | 역할 | 핵심 콘텐츠 |
|------|------|-------------|
| Hero | 브랜드 첫인상 | 상호, 슬로건, 대표 비주얼, 주문 CTA |
| About / USP | 차별점 | 배달 전문, 중식 특화, 신선함·양 등 강점 2~3개 |
| Menu | 메뉴 홍보 | 짜장면, 짬뽕, 탕수육 등 대표 메뉴 카드 (이미지, 설명, 가격) |
| Reviews | 고객 평가 | 별점, 후기 텍스트, 작성자(닉네임), 주문 메뉴(선택) |
| Order CTA | 주문 유도 | 배달 앱 링크, 전화번호, 영업·배달 가능 시간 |
| Footer | 정보 | 주소, 연락처, 저작권, SNS(선택) |

## 콘텐츠 방향

### 확정
- 브랜드명: **남다른 음식**
- 장르: **중식**, **배달 전문**
- 페이지 성격: **홍보 랜딩** (메뉴 + 리뷰 중심)

### 구현 시 채울 내용 (미확정)
- 슬로건·헤드라인 카피
- 대표 메뉴 목록·가격·이미지
- 실제 또는 샘플 고객 리뷰 데이터
- 배달 앱 URL (배민, 쿠팡이츠 등)
- 매장 연락처·영업시간
- 브랜드 컬러 (중식·따뜻함 연상: 레드, 골드, 다크 톤 등)

## UX 원칙
- **모바일 우선**: 배달 고객 대부분이 스마트폰 사용
- **음식 비주얼 강조**: 메뉴 사진이 텍스트보다 먼저 눈에 들어오게
- **리뷰는 짧고 진짜처럼**: 1~3문장, 별점, 닉네임으로 스캔 가능하게
- **CTA 반복**: Hero·메뉴 하단·리뷰 후·Footer에 주문 경로 노출
- **과한 애니메이션 지양**: 로딩·스크롤 성능 우선
